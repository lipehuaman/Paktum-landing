# Paktum-landing
Landing page for Paktum — sports sponsorship management software.

## Local preview

Run `python3 scripts/serve.py` and open <http://localhost:8765/>. The preview supports the extensionless page URLs used in production. English and Spanish home pages are at `/en/` and `/es/`. Blog links open the existing published blog; its source is hosted separately.

## Home pages

Home copy lives in `content/home.json` (DE, EN, ES). Layout is generated by `scripts/build-home.py`; styles and interactions are shared in `home.css` and `home.js`.

After editing the copy or template, run:

```sh
python3 scripts/build-home.py
```

The hero shows a scripted replica of the Position Editor and Analytics (`heroDemo` strings in `content/home.json`). The screen rises into the hero in 3D, then plays a 14-second loop: select boards, move one, book them and see the revenue in Analytics. It is not interactive, stops while off-screen and does not play with reduced motion. Scroll reveals, parallax and hover effects are also in `home.js`.

The generated HTML includes its content and structured data without requiring JavaScript. The product tour loads when opened; the menu, dialog and keyboard behaviour are enhanced by `home.js`.

`python3 scripts/build-home-media.py` prepares home screenshots and 72-second tours from the existing local feature videos. It requires FFmpeg. Existing media is reused; remove a generated asset explicitly before rebuilding it. Captions are regenerated from the home content.

## Navigation

All pages share one navbar, defined in `scripts/site_nav.py` with `site-nav.css` and `site-nav.js`. It follows the client brief: Features (with module dropdown), References, Pricing, Blog, About us, plus language, LinkedIn and Book a demo. The home pages get it from `build-home.py`; for every other page run:

```sh
python3 scripts/build-nav.py
```

The blog (separate `paktum-blog` project) carries a copy of this navbar in `src/layouts/BaseLayout.astro`, `src/styles/site-nav.css` and `src/scripts/site-nav.js`. Update it there too when the navbar changes.

## Features page

The module tour on `/features` is generated from `content/features.json` by `scripts/build-features.py`, with `features-story.css` and `features-story.js`. Wide screens show one text block per module on the left and a sticky app window on the right; the module at the viewport midpoint becomes active, plays its video and updates the 01–09 control and the URL hash. Smaller screens stack text and video. Videos skip their title card and closing logo. Posters (`videos/features/*-ui.jpg`) show the product. After editing the copy, run:

```sh
python3 scripts/build-features.py
```

The local preview server supports byte ranges, so videos can seek as they do on Vercel.
